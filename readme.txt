Author: Jasbir Kaur Dhaliwal

Purpose:
Inspired by the idea of helping travellers and visitors discover festival open houses and cultural events in Malaysia.
See: https://lnkd.in/p/g5KfxjEp

Installation Guide:
1. Install the required libraries:
   pip install -r requirements.txt

2. Replace the dummy API key in settings.py with your own API key.

Output:
- The output folder contains the generated HTML page listing the discovered open houses.
- A WhatsApp-ready message is also generated for easy viewing and sharing on mobile devices.
